> בתוך המאגר: התמונות שה-README מזכיר (`assets/...`) נמצאות ב-`web/assets/` (למשל `web/assets/clouds.webp`, `web/assets/mascot.png`, `web/assets/lang/`). הערכים המדויקים של הצבעים, המרווחים והגופנים: `tokens.json` כאן, ובקוד: `web/style/main.css`.

Code-Iot היא אפליקציה ללימוד תכנות בעברית ובאנגלית, בסגנון משחק: מסלול של צמתים, XP, רצפים ותגים. המראה הוא **פאנלים כהים בכחול לילה מעל שמיים מצוירים**, עם **זהב** כצבע הפעולה ו**סגול** לפרויקטים. כל רכיב לחיץ נראה כמו כפתור משחק: קצה תלת־ממדי מוצק מתחתיו, ובלחיצה הוא "שוקע".

## עקרונות

- **שמיים מאחור, לילה מקדימה.** הרקע הוא תמונת העננים (`assets/Backgrounds/clouds.webp`) על `sky`. כל תוכן יושב בפאנלים של `surface` עם מסגרת `line`. לא שמים טקסט קטן ישירות על העננים.
- **זהב אחד לפעולה.** `primary` הוא הצבע של "עשה את זה עכשיו": כפתור ראשי אחד במסך, הצומת הבא, ה-XP, הלשונית הפעילה. לא משתמשים בו לקישוט.
- **קצה מוצק, לא צל מטושטש.** כרטיסים מקבלים `shadow-card`, כפתורים מקבלים קצה בצבע הכהה שלהם (`shadow-btn-primary`, `shadow-btn-ghost`, `shadow-btn-danger`). צל רך מותר רק מתחת לצמתים (`shadow-node`).
- **מימין לשמאל כברירת מחדל.** הממשק מתהפך לפי השפה (`dir="rtl"` בעברית). קוד, מספרי טלפון, סכומים ושמות שפות תמיד `dir="ltr"` או בתוך `<bdi>`.

## צבע

| תפקיד | טוקן | הערה |
|---|---|---|
| רקע הדף | `sky` + תמונת העננים | אף פעם לא טקסט קטן עליו |
| פאנל / כרטיס | `surface`, מסגרת `line` 2px | טקסט `text`, משני `muted` |
| משטח מוגבה | `surface-2` | אריח אייקון, תגית, מסילת התקדמות |
| נגן שיעור / עורך | `bg`, `bg-2` | |
| קוד | `code-text` על `code-bg` | 15.4:1 |
| פעולה | `primary`, טקסט `on-primary`, קצה `primary-dark` | 10.3:1 |
| פרויקט | `purple`, `purple-light` → `purple`, קצה `purple-dark` | |
| נכון / שגוי | `success` (אייקון `on-success`) / `danger` | |
| רצף | `streak`, `streak-card` | |
| הודעת אישור | `note-ok-bg` + מסגרת `note-ok-border`, טקסט לבן | 7.3:1 |
| הודעת שגיאה | `note-error-bg` + מסגרת `danger`, טקסט לבן | 10.3:1 |

- טקסט ראשי תמיד `text` על `surface`, `surface-2` או `bg`. טקסט משני `muted` (7.2:1 על `surface`).
- `danger` כטקסט רק בגודל 19px ומשקל bold ומעלה (3.9:1 על `surface`). לטקסט קטן משתמשים בהודעת שגיאה.
- **שתי תגיות סטטוס חלשות בניגודיות** ומופיעות כאן כמו שהן בקוד: לבן על `status-paid` (4.0:1) ולבן על `status-warning` (3.6:1). הן עוברות רק כטקסט קטן מודגש מאוד. בעיצוב חדש, השתמשו ב-`on-primary` על `status-warning`.
- `blue` ו-`blue-deep` שייכים לרקע השרטוט הישן. אל תשתמשו בהם בעיצוב חדש.

## טיפוגרפיה

- **כותרות:** Fredoka (`display`), במשקל 700. בעברית הדפדפן נופל ל-Rubik.
- **טקסט:** Nunito (`body`), במשקלים 700 עד 900. גם כאן Rubik לעברית.
- **קוד:** JetBrains Mono (`mono`). מילות הרקע ב-Fira Code (`codeword`).
- כל הגופנים נטענים מ-Google Fonts: `Fredoka 500;600;700`, `Nunito 500;700;800;900`, `Rubik 400;500;700;800`, `JetBrains Mono 400;600`, `Fira Code 400;500`.
- **סולם:** `welcome-title` 46, `auth-title` 30, `topbar-title` 26, `prompt` 22, `section-title` 20, `card-title` 19, `button` 16/900, `body` 16, `code` 15, `small` 13, `meta` 12.
- טקסט כפתור באנגלית באותיות גדולות עם ריווח 0.04em. בעברית אין אותיות גדולות, והריווח נשאר.
- **טקסט לבן ישירות על העננים** (כותרות עמוד, קישורים, "חזרה") מקבל קו מתאר שחור דק: `text-shadow` של 1px בשמונה כיוונים ב-`#000`.

## צורה ומרווחים

- **רדיוסים:** `radius` (16) לכרטיסים, `radius-lg` (14) לכפתורים ולבלוקי קוד, `radius-md` (12) להודעות ולשדות, `radius-xs` (8) לתגיות, `radius-node` (18) לצמתים, `radius-pill` לפסי התקדמות.
- **מרווחים:** הסולם הוא 4, 6, 8, 10, 12, 14, 16, 18 ו-28. ריפוד כרטיס `space-7` (16), רווח בין כרטיסים `space-5` (12), gap בין כפתורים `space-3` (8).
- **שוליים:** 16px בטלפון. בדסקטופ יש ניווט צדדי ופאנל צד ליד המסלול.

## רכיבים (כפי שהם בקוד)

- **כפתור ראשי:** רקע `primary`, טקסט `on-primary`, ריפוד 14×20, `radius-lg`, `shadow-btn-primary`. בלחיצה `translateY(2px)`.
- **כפתור משני (ghost):** רקע `surface`, מסגרת `line` 1px, `shadow-btn-ghost`. **מתאר (outline):** מסגרת `text` 2px על navy שקוף 55%.
- **כפתור danger:** רקע `danger`, טקסט לבן, `shadow-btn-danger`. רק לפעולות שאי אפשר לבטל, תמיד עם חלון אישור.
- **כרטיס מסלול:** `surface`, מסגרת `line` 2px, `radius`, `shadow-card`. כשהוא נבחר, המסגרת היא `primary`. אריח הסמל 56×56 על `surface-2`.
- **צומת במסלול:** 72×72, `radius-node`. רגיל: מעבר מ-`line` ל-`#263467`. הושלם: מעבר מ-`primary-light` ל-`primary`. פרויקט: 80×80 בסגול. נעול: `locked`. הצומת הנוכחי מקבל `outline` של 3px ב-`primary` ופועם.
- **תגית:** 12px/900, `radius-xs`. הצבעים: `surface-2`, `primary` עם `on-primary`, או סטטוס.
- **הודעות:** אישור (`note-ok-…`) ושגיאה (`note-error-bg`) תמיד אטומות. לא משתמשים בהן שקופות על העננים.

## תנועה

- כפתורים שוקעים 2px ב-60ms. צמתים שוקעים 5px.
- פס ההתקדמות מתמלא ב-400ms עם `cubic-bezier(.2,.9,.3,1.2)`.
- הצומת הנוכחי פועם (glow) כל 1.8 שניות.
- **מילות הקוד ברקע** עולות לאט, 20 עד 60 שניות לכל מילה, ורק במסכי הפתיחה, ההתחברות וההרשמה. בכל שאר המסכים רואים רק עננים.
